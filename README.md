# 永恒 · 凡界 v0.1.19

TypeScript 编写的修仙增量游戏初版试玩，包含战斗、背包、功法、洞府四个页面，可在 Windows 11 的 Edge 或 Chrome 中离线打开。

当前历练包含10个大关卡，取消小关卡。每关有4种同强度普通怪无限轮换，累计击杀填充首领进度。进度满后仍继续刷怪，玩家点击“挑战首领”才进入首领战；击败首领后仅解锁下一关，留在原关继续刷怪。首领只可击败一次。清怪目标由8只逐关递增至44只，关卡名称与数值见 [docs/levels.md](docs/levels.md)。

战斗区通过一个“选择关卡”按钮打开关卡弹窗。未解锁项右侧显示锁图标且无法进入，已解锁项可随时切换，保留各关进度。移除了原来的区域长列表和逐个怪物关卡入口。

v0.1.12将游戏名称统一为“永恒”，左栏顶部标题水平居中，沿用原有字体、字号、字重与配色。浏览器标签页同步显示“当前页面 · 永恒”。生产构建与六页面八种宽度的浏览器验证通过，效果见 [标题验证记录](docs/design-qa-brand-v0.1.12.md)。

v0.1.13统一全界面栏目分隔线：横线延伸到所在容器左右边缘，栏目用连续细线分隔；文字和控件保留内边距。桌面背包竖线连接上下边界，境界和关卡弹窗列表按行分隔。该标准适用于后续新增栏目。构建与浏览器检查通过，效果见 [栏目分隔线验证](docs/design-qa-dividers-v0.1.13.md)。

v0.1.14按用户指定布局重排10个装备槽，并移除装备区人物立绘。两个戒指分别占格，装备槽文字保持居中。构建与浏览器回归通过，见 [装备布局验证](docs/design-qa-equipment-v0.1.14.md)。

v0.1.16移除左侧“境界”“说明”入口、对应资料页和规则弹窗。完整资料保存在 [境界表](docs/realms.md)、[成长与升级数值](docs/balance.md)及[游戏规则](docs/game-rules.md)，供后续开发读取。角色当前境界和突破功能保留，界面沿用v0.1.14；已撤回的v0.1.15不复用。44项规则测试、构建与浏览器回归通过，见 [验证记录](docs/design-qa-four-pages-v0.1.16.md)。

v0.1.17为每个装备槽加入一件“测试用＋部位名”装备，初始存放背包，共10件。支持鼠标与触屏拖动穿戴、卸下和交换位置，背包选中格显示边框。测试装备不附加属性。49项规则测试、生产构建和浏览器回归通过，见 [测试装备验证](docs/design-qa-equipment-v0.1.17.md)。

v0.1.18加入背包右键小菜单，在物品右侧由上到下显示“装备、分解、出售”。装备优先放入对应空槽；分解与出售按当前要求直接移除装备，暂不给收益。51项规则测试、生产构建及浏览器回归通过，见 [右键菜单验证](docs/design-qa-inventory-menu-v0.1.18.md)。

v0.1.19接入六档稀有度颜色边框：常见白、普通绿、稀有蓝、罕见紫、珍稀金、绝世红。背包和装备槽采用直角约3px内嵌高光框；选中时白色四角贴近边框，空槽保持灰框。游戏内不显示稀有度名称。51项规则测试、构建及浏览器回归通过，见 [边框核对](docs/design-qa-rarity-v0.1.19.md)。

## Windows 11 直接打开

完整解压 `永恒-v0.1.19.zip`，双击 `index.html`，使用 Edge 或 Chrome 打开。保留 `game.js`、`game.css`、`icons` 与 `actors` 文件夹。源码另见 `永恒源码-v0.1.19.zip`；后续每次修改交付递增版本号。

构建产物不依赖 Node.js、网络、账号或在线服务，尚未封装为 exe。

## 当前玩法

- 打开后自动战斗，空手每秒攻击一次，初始伤害10。点击立绘不会攻击，切换页面与突破不重置攻击计时。
- 初始为炼气一层，生命100、攻击10、防御2、回血1点/秒、修为0/100。修为达标后可直接突破小阶段，扣除门槛并保留溢出修为。
- 六次跨境界闭关依次耗时5至10秒，成功率80%、70%、60%、50%、40%、30%，失败扣除门槛的10%；闭关期间自动战斗继续。
- 10关强度沿既有33阶段成长曲线插值，首尾对应炼气一层和大乘圆满。同关普通怪强度相同，生命60乘倍率，奖励10乘倍率；回刷旧关数值固定。怪物暂不反击。
- 普通怪每次击杀有20%概率掉落2至5铜钱；首领生命与修为为同关普通怪的5倍，固定奖励关卡序号乘10的铜钱，不额外抽普通怪掉落。
- 初始背包存放10件测试装备，铜钱在同一格堆叠。每页24格，翻页按钮居中位于格子下方，可主动打开空白下一页，掉落不改变正在查看的页码。
- 装备区删除人物立绘，改为四行三列的10个空槽，首行和末行左格留空；排列依次为头盔／项链，主武器／胸甲／副武器，护腕／裤子／戒指，鞋子／戒指，可拖动测试装备到对应槽位穿戴，拖回背包卸下；两个戒指独立，并可互换。
- 背包可拖动调整物品位置，点击格子显示选中边框；也可先选中装备，再点击对应槽穿戴，选中空格后点击已穿戴槽卸下。键盘方向键选择背包格，回车/空格选中或穿戴，装备槽按Delete卸下。
- 测试装备循环覆盖六档稀有度，边框颜色随穿戴、卸下、交换保留；铜钱为常见白框。稀有度目前仅表示颜色，不影响属性或收益。
- 背包物品右键打开操作菜单，三项顺序为装备、分解、出售；靠近边缘自动调整位置。装备优先空槽，再替换同部位装备；分解和出售立即移除所选装备，不给予铜钱或材料。铜钱的三项操作暂不开放。点击外部、Escape、翻页或切换页面关闭菜单；键盘Shift+F10也能打开。
- 角色信息保留当前境界与突破操作。完整境界表、成长数值、已确认与待确认规则仅保存在仓库文档，游戏内不再显示资料页。功法和洞府的具体收益、装备属性仍待确认。

当前没有存档：刷新或重新打开页面会重置关卡、角色和背包，不结算关闭期间收益。

## 界面

沿用深灰主区、较深侧栏、暖白文字与玉青色强调。角色信息、属性、修为与突破位于最左侧栏顶部，主导航排在下方；窄屏时信息与属性并排置于顶部。最近记录默认显示一条，展开后查看最近八条。

战斗区保留白灰道袍的像素主角；右侧像素灰狼继续作为临时敌怪外观。怪物血条位于立绘头顶，受击闪白180毫秒、伤害浮字650毫秒。修为实际到账后，在左栏修为数字上方显示“+数值”，450毫秒内上浮消失。系统开启“减少动态效果”后取消位移、闪白与伤害浮字，到账提示短暂静态显示。动效不参与结算或消耗掉落随机数。

## 开发与验证

使用 Node.js 22.18 或以上版本：

```bash
npm install
npm run dev
npm test
npm run build
npm run test:browser
```

也可双击 `启动开发.cmd`。构建后直接打开 `dist/index.html`；产物使用 IIFE 脚本，不通过 fetch 加载数据。

浏览器验证使用 `/usr/bin/chromium` 和本机临时静态服务，结束后关闭服务；可传入已有地址，例如 `npm run test:browser -- http://127.0.0.1:4173/`。Chromium 不是运行发行游戏所需的依赖。

v0.1.11已通过44项规则测试、生产构建与Chromium浏览器验证。规则测试覆盖10关完整推进、无限轮换、进度与解锁门槛、首领一次性奖励、跨关进度保留、全部大境界闭关和奖励守恒。浏览器覆盖关卡弹窗、锁图标与禁用、手动首领战、前五关实际推进、闭关失败重试、弹窗焦点保留，并回归自动战斗、到账浮字、背包、掉落和六页面八种宽度。截图与验证记录见 [docs/design-qa-areas-v0.1.11.md](docs/design-qa-areas-v0.1.11.md)。Windows 11 实机双击运行尚未验证。
