# 游戏规则与待确认内容

本文件保存原“说明”页面的资料，仅供仓库内开发查阅，不在游戏中展示。

完整境界表见[realms.md](realms.md)，成长与修为公式见[balance.md](balance.md)，总体设计见[framework.md](framework.md)，大关卡见[levels.md](levels.md)。游戏保留当前境界和突破操作，移除独立“境界”“说明”页面及规则弹窗。

## 已确认规则

### 刷怪获取修为

战斗采用纯自动攻击，进入游戏后自动开始；击败怪物获取修为，后续可掉落功法。

### 双向战斗框架

双方互相攻击是已确认的战斗方向；当前先配置怪物生命，怪物攻击暂不加入数值。

### 怪物生命

普通怪初始生命60，首领300，按怪物自身实力使用已确认的成长倍率。生命配置固定，玩家变强后回刷旧区域可更快击杀。

### 关卡与怪物名称

已配置10个大关卡，由山野小径至混沌天渊；每关有4种轮换普通怪和1名首领。普通怪无限刷新，不设小关卡；初始尖牙野鼠生命60、击杀修为10。

### 清怪推进与回刷

每关累计击败普通怪填充首领进度，目标从第1关8只逐关增加到第10关44只。进度满后继续刷怪，由玩家手动挑战首领；胜利解锁下一关。通过“选择关卡”弹窗切换已解锁关卡，切换保留各关进度。

### 首领固定奖励

首领生命为同强度普通怪的5倍，提供5倍修为，固定奖励本区域序号乘10的铜钱。首领只能击败一次，奖励不重复发放；战后留在本关继续刷普通怪。

### 铜钱测试掉落

每次击败当前普通怪后独立进行20%掉落判定；成功时等概率获得2至5个铜钱，自动存入背包并在同一个格子累加数量。

### 人物装备槽

背包左侧展示10个装备槽：首行头盔、项链；第二行主武器、胸甲、副武器；第三行护腕、裤子、戒指；第四行鞋子、戒指。首行与第四行左格留空；右侧展示背包物品格子。

初始背包放入10件“测试用＋部位名”装备，每个槽位一件，两个戒指独立。支持鼠标与触屏按部位拖动穿戴、拖回背包卸下、同部位替换及戒指互换；部位不符拒绝操作。测试装备暂不增加属性。

背包物品支持拖动换位，点击选中后显示边框，空格也可选中。先选装备再点击对应槽可穿戴，选空格后点击已穿戴槽可卸下；键盘方向键切换背包选择，回车/空格操作，装备槽Delete卸下。

### 物品稀有度

| 档位 | 边框颜色 | 色值 |
| --- | --- | --- |
| 常见 | 白色 | #F0F0F0 |
| 普通 | 绿色 | #55C77A |
| 稀有 | 蓝色 | #549EFC |
| 罕见 | 紫色 | #AF7CFA |
| 珍稀 | 金色 | #E8BE54 |
| 绝世 | 红色 | #EB5F60 |

游戏内仅使用边框颜色区分稀有度，不显示稀有度名称、前缀或标签。物品名称原色，背包与装备槽统一使用直角3px框及克制内沿高光；空槽1px灰框。选中为白色四角加背景提亮，白线距边框约1px，不覆盖稀有度色。

10件测试装备依次循环六档，铜钱为常见；穿戴、卸下、交换保留稀有度。当前稀有度不影响属性或收益，正式掉落分布和数值加成待另行确认。

### 背包右键菜单

右键背包物品后，在物品右侧弹出小栏，由上到下为“装备、分解、出售”。装备优先兼容空槽，无空槽时替换同部位装备，旧装备返回来源格。两个戒指依次填空。

用户已确认：分解、出售直接移除所选背包装备，暂不给收益，不删除其他物品或已穿戴装备。铜钱的这三项操作暂不开放。菜单在空间不足时换侧，保持视口内可用；外部点击、Escape、翻页、切换页面与拖动关闭。

### 背包分页

每页24个紧凑格子，满页时自动增加空白下一页，也可以主动进入下一页；翻页按钮在格子正下方居中。翻页只改变展示，物品位置与铜钱堆叠保持原规则。

### 当前伤害结算

当前每次伤害直接使用角色攻击值，怪物暂不反击；防御等后续伤害机制另行确认。

### 玩家持续回血

生命回复速率仅属于玩家，战斗、脱战和休整时均生效。

### 基础属性与成长

初始生命100、攻击10、防御2、回血1点/秒。生命、攻击、防御和回血同境界首尾累计3倍，跨大境界再变为3倍；空手攻速固定为每秒1次，单次伤害沿用角色攻击值。

### 战败后休整

玩家被击败后休整恢复生命，恢复后可继续挑战。

### 区域刷怪

已解锁区域可持续刷怪；更高难度的区域需要清理更多普通怪，才能解锁首领。

### 首领开启新区域

击败区域首领后开放下一级区域。首领为一次性，击败后不再出现，普通怪仍可刷取。

### 功法装配

功法采用分类槽位；装配后提供被动属性加成，部分功法附带主动技能。

### 小阶段直接突破

修为达到要求后，可以直接突破到下一个小阶段。

### 阶段修为门槛

炼气一层升二层需100修为，各阶段数值已配置，完整门槛见仓库 docs/balance.md。

### 突破成功结算

成功突破扣除本阶段所需修为，溢出部分保留到下一阶段。

### 关卡强度与修为

10个大关卡在现有33个境界阶段的成长曲线上插值，从炼气一层提升至大乘圆满；同一关4种普通怪强度相同。普通怪生命为60乘固定强度倍率、修为为10乘倍率，回刷时不随玩家境界变化。

### 大境界闭关突破

修为达标后闭关，等待数秒读条，再按当前概率判定。境界越高，基础成功率越低。

### 突破失败可重试

闭关突破失败会扣除部分修为，修为重新达到要求后可再次尝试。

### 闭关数值

六次跨境界闭关依次耗时5至10秒，成功率依次为80%、70%、60%、50%、40%、30%；失败扣除当前突破门槛的10%。闭关期间自动战斗继续。

### 筑基开启洞府

到达筑基期后解锁洞府及自动修炼，升级洞府可提高自动修炼的修为收益。

### 后续扩展

后续增加丹药系统、其他世界及动画表现，具体内容待确认。
