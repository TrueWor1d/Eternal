# 装备槽排列 v0.1.14

删除背包装备区中央的人物立绘，保留战斗区主角。装备空槽改为四行三列，共10个，两个空位不绘制方框：

| 左列 | 中列 | 右列 |
| --- | --- | --- |
| | 头盔 | 项链 |
| 主武器 | 胸甲 | 副武器 |
| 护腕 | 裤子 | 戒指 |
| | 鞋子 | 戒指 |

槽位尺寸一致，名称和未装备状态在格内居中。项链、裤子、戒指使用与现有装备一致的本地图标，来源与许可见public/icons/gear/README.md。当前仍仅展示空槽，未加入装备属性、掉落或穿戴逻辑。

## 验证

- TypeScript检查与生产构建通过。
- 浏览器回归核对10个槽位及指定行列、两个独立戒指格、未装备状态、图标完整性和装备区人物移除。
- 六页面及8种窗口宽度（320至1920像素），装备与背包布局正常，没有横向溢出。
- 回归战斗区主角、自动战斗、铜钱堆叠、背包分页、到账浮字、关卡推进和闭关。
- 人工查看1366像素桌面、390像素手机与320像素窄屏截图，排列符合指定布局。
