# 纯自动战斗核对 · v0.1.2

逻辑测试、生产构建与Chromium浏览器检查均通过。

## 实现范围

- 打开游戏即开始自动战斗，第一击在一秒后发生；当前空手攻速在所有阶段均固定为每秒一次。
- 移除手动攻击按钮、自动攻击开关与立绘攻击事件；灰狼改为普通展示元素，取消悬停和按压反馈。
- 单次伤害继续使用角色攻击值，初始为10，保留原攻击成长；击杀后刷新同一配置的怪物并继续战斗。
- 导航和突破不重新创建攻击计时器，不重置下一击时间；从背包页直接打开游戏也会开始自动战斗。
- 铜钱的20%掉率、2至5数量范围与同格堆叠保持原规则。武器及装备属性留待后续确认。

## 验证结果

- 30项逻辑测试通过，包括所有境界空手攻速为1、原攻击成长、掉率与数量边界、堆叠和击杀结算防重复。
- TypeScript检查与生产构建通过。
- 浏览器验证不足一秒不攻击，满一秒扣10生命，六秒击杀并仅获得10修为；点击立绘不会额外攻击。
- 多次切页后仍然每秒一次；在半个攻击间隔时突破，下一击仍在原一秒边界发生，伤害按成长后的角色攻击值结算。
- 自动战斗中开启背包，先掉2个、后掉5个铜钱，即时显示同格累计7个；之后未触发掉落时数量保持7。
- 验证记录展开时焦点保留、键盘跳转、规则弹窗及关闭、七境界数值表，以及六页面在1920、1440、1366、1024、768、700、390、320px宽度下没有页面级横向溢出。
- 浏览器控制台错误0、外部请求0。随机数控制仅存在于测试页面，发行构建使用正常Math.random。
