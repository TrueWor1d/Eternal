# 像素主角与装备布局核对 · v0.1.4

逻辑测试、生产构建与Chromium浏览器检查均通过。

## 实现范围

- 采用用户选定的白灰道袍、束发、空手、朝右站立的像素修真者。参考已选角色，通过Image Gen导出透明PNG并接入本地素材。
- 战斗页与背包装备区共用`public/actors/player.png`，图片1024×1536、RGBA，采用像素方式显示。
- 装备区中央显示角色，8个空槽在两侧对称排列。自上而下四排为：头盔／胸甲、左护腕／右护腕、主武器／副武器、左靴／右靴。
- 保留装备在左、物品背包在右的页面布局，较窄窗口改为上下分区，装备区内部始终保持角色居中、槽位在两侧。
- 当前装备槽均未装备，未增加装备资料、穿戴、属性、动画或新的掉落规则。

## 验证结果

- 30项既有逻辑测试、TypeScript检查及生产构建通过。
- 浏览器确认战斗与装备使用同一个主角图片、图片成功加载，两个位置均使用像素显示。
- 六个页面在1920、1440、1366、1024、768、700、390、320px宽度下没有页面级横向溢出。
- 每种窗口宽度核对中央角色位于左右装备之间、两侧槽位同排等宽、以角色中心对称，四排自上而下显示；物品格保持方形、宽度至少48px。
- 验证纯自动攻击、每秒一次、原伤害成长、导航及突破连续计时、修为奖励与突破、铜钱实时堆叠、记录展开和键盘操作。
- 浏览器控制台错误0、外部请求0。发行构建没有测试用随机数覆盖。
