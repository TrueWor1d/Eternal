# 全局栏目分隔线验证 v0.1.13

所有栏目统一使用连续1px细线分隔。横线连接所在容器左右边缘，文字、按钮与其他内容保留各自内边距。标准已记录在AGENTS.md，适用于后续所有新增栏目。

## 本版覆盖

- 侧栏名称、角色信息、修为、属性与导航的分隔线均接到栏边。窄屏角色信息与属性之间的竖线连接上下横线。
- 页面标题、战斗记录、功法、洞府、境界及说明各栏的横线延伸至主内容区左右边缘。
- 桌面背包的竖线连接标题下方与页脚边界，窄屏上下排列时改用横线接到左右边缘。
- 境界和关卡弹窗的栏目使用连续行分隔，待确认内容弹窗的分隔线同样连接弹窗两侧。
- 物品格子、装备槽、按钮、标签与数据表等控件保留原有形态。游戏规则未修改。

## 验证

- TypeScript检查与生产构建通过。
- 六页面×八种宽度（320、390、700、768、1024、1366、1440、1920像素）核对分隔线实际坐标，两端与容器边缘误差不超过1像素，无页面横向溢出。
- 两个弹窗在桌面和手机下核对分隔线坐标、内部横向溢出与关闭操作；正常。
- 桌面背包竖线连接标题与页脚。窄屏竖线在700、390、320像素下，六页面均连接侧栏上下横线。
- 完整Chromium浏览器回归通过：无限刷怪、手动首领、关卡解锁、闭关重试、到账浮字、减少动态效果、背包分页、铜钱堆叠与焦点保持；控制台错误0，外部请求0。
- 人工查看桌面与手机效果图，核对边线接合及内容边距。
