# 移除境界与说明资料页 v0.1.16

游戏左侧仅保留战斗、背包、功法、洞府四个入口。删除独立境界资料页、说明页和待确认规则弹窗，页面函数、展开状态、点击处理及专用样式一并移除。旧的#realms和#handbook地址按未知页面规则显示战斗，不再展示资料内容。

## 外部资料

- [realms.md](realms.md)：原境界页的七大境界、33个阶段数值表。
- [balance.md](balance.md)：成长曲线、属性公式与32次升级需求。
- [game-rules.md](game-rules.md)：原说明页25条已确认规则与4条待确认内容。
- [framework.md](framework.md)：当前设计范围和开发设定。

这些资料供开发直接读取，不加载到游戏页面。角色信息中的当前境界、修为、属性与突破操作保留，游戏规则与v0.1.14相同，未重新加入已撤回的模块边框配色。版本号跳过已撤回的v0.1.15，避免旧链接被复用。

## 验证

- 44项规则测试通过；TypeScript与生产构建通过。
- 浏览器核对主导航仅有4个入口，没有境界、说明或规则弹窗的DOM。直接打开旧地址显示战斗且自动攻击正常。
- 四页面×8种窗口宽度没有横向溢出，10格装备排列、自动战斗、背包分页、铜钱堆叠、到账浮字、手动首领、关卡解锁与闭关回归通过。
- 额外核对外部文档包含全部33个阶段、25条规则和4条待确认内容；发行脚本不包含已移除资料页的内容。
- 人工核对桌面与手机截图，当前境界与突破按钮仍可见。
