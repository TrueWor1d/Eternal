# 背包右键菜单 v0.1.18

右键背包物品，在物品右侧显示小栏，三个选项由上到下排列为“装备、分解、出售”。三行文字在按钮内水平、垂直居中，行间细线连接菜单边缘，沿用现有配色。打开时选中目标格；右侧或下方空间不足时换侧或调整高度，保持菜单在视口内。

“装备”优先进入对应空槽，两个戒指依次填空；没有空槽时替换第一个兼容槽，旧装备回到来源背包格。分解与出售按用户明确选择直接移除该件背包装备，暂不提供铜钱或材料。不会移除其他物品或已穿戴装备。铜钱的这三项操作暂不开放。

菜单支持ContextMenu键、Shift+F10、方向键、Home、End、回车与空格。Escape关闭并返回原格，Tab关闭后继续移动焦点；点击外部、翻页、切换页面或拖动也会关闭。自动掉落时只刷新背包格，保留菜单、焦点与目标物品ID。

## 验证

- 51项规则测试通过：覆盖空槽选择、两戒指顺序、满槽替换选择、指定背包装备移除、不发放收益、不误删铜钱、已穿戴物品或另一戒指；原有规则保持通过。
- TypeScript检查、离线生产构建通过。
- Chromium核对右键菜单三项顺序、位于物品右侧、装备与分解/出售操作、选中边框、键盘打开与导航、Escape/外部点击/翻页/页面切换/拖动关闭。
- 打开菜单期间普通怪掉落后，焦点与菜单保留；分解和出售仅移除各一件装备，铜钱不变。
- 1920、1024、768、700、390、320像素下菜单保持视口内；回归四页面八种宽度、鼠标/触屏拖放、自动战斗、关卡推进与闭关。
- 浏览器没有运行异常或外部请求。验证使用本机临时HTTP服务；Windows 11实机双击尚未验证。
