## 比较历史与修复

- [P2] 底部重置提示未完整出现在首屏。实现页面高800px，而参照在768px画面内显示完整提示。需要压缩敌怪区、属性行及记录区的间距，保留字号与主要操作面积，并复查页面高度。
- [P2] 自动攻击开关偏小，导致主按钮过宽。局部比较中实现使用42×24px开关，参照约为64×34px。放大桌面开关和标签，并给血条与按钮增加16px内缩。
- [P3] 标准图标的具体形状与生成稿略有差异。采用本地 Microsoft Fluent 图标，替代生成稿中的标准图标，不引入自制插画；后续可微调图标风格。

## 已检查的表面

- 字体：系统无衬线字体，正文16px，属性18px，标题22/36px；Windows 优先使用 Segoe UI/微软雅黑，当前 Linux 截图使用 Noto Sans CJK 后备字体。
- 排版：左侧导航、角色栏、战斗栏以及轻量分隔线与参照结构一致；首屏高度问题已修复并通过最终浏览器断言。
- 颜色：主区#212121、侧栏#171717、文字#ececec、次要文字#afafaf、分隔线#383838；未保留蓝色或水墨主题。
- 图像：参照没有需生成的插画，所有图标均来自图标库并包含本地许可；页面不依赖外部字体或图片服务。
- 文案：导航为战斗、功法、洞府、境界、说明，敌怪仍为[待编辑]；未加入新玩法。
- 交互：手动/自动攻击、奖励与刷新、突破、切页状态保留、记录展开/收起、自动攻击期间展开按钮焦点、数值表及8种宽度已通过浏览器检查；无控制台错误及外部请求。
