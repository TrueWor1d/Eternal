## 成长曲线

- 每个境界的首阶段到末阶段，生命、攻击、防御、生命回复累计变为 3 倍。
- 跨入下一大境界的初期，上述属性再变为 3 倍。
- 炼气共 8 次小突破，每次倍率为 `3^(1/8)`，约 1.1472026904。
- 其余境界各 3 次小突破，每次倍率为 `3^(1/3)`，约 1.4422495703。
- 按最新确认规则，空手攻速固定为每秒1次，不随境界提升；武器对属性的影响后续确定。
- 计算始终从初始值乘累计倍率得到，内部保留小数；生命、攻击、防御仅在显示时取整，速率显示保留适当小数。

设大境界序号 `r` 从 0 到 6，小阶段序号 `i` 从 0 开始，小突破次数为 `d`（炼气为 8，其余为 3）：

```text
基础属性倍率 = 9^r × 3^(i/d)
空手攻速 = 1 次/秒
```

## 成功结算

- 成功突破扣除本阶段所需修为，溢出保留到下一阶段。
- 单次小突破只前进一个阶段。
- 大境界仍须闭关判定成功，不能通过小突破接口直接越境。
- 成功结算函数输出下一阶段、余额和新基础属性，不增加突破回血效果。
- v0.1.8为支持完整关卡推进配置闭关：六次跨境界依次耗时5至10秒，成功率依次为80%、70%、60%、50%、40%、30%，失败扣除当前突破门槛的10%。

## 普通怪奖励参考

```text
普通怪修为参考 = 10 × 对应怪物自身实力的基础属性倍率
```

起始普通怪参考 10 修为，筑基初期实力参考 90，金丹初期实力参考 810，大乘初期实力参考 5,314,410。参考值在配置怪物资料时使用，输入为怪物自身实力，不读取玩家当前境界。v0.1.11已配置10个大关，每关4种普通怪共享固定强度，具体插值、清怪目标和首领奖励见[levels.md](levels.md)。

此前 7～11 小时是仅按同等实力普通怪 5～8 秒/只估算的净刷怪量，不是实际通关时长保证；洞府、功法、休整及闭关失败仍会影响节奏。

## 怪物生命

- 普通怪初始生命 60，首领初始生命 300。
- 普通怪生命为对应实力阶段的角色基础攻击乘 6；首领生命为乘 30。
- 两者均使用已批准的境界成长倍率，计算输入为怪物自身配置的实力阶段。
- 怪物生命配置后固定，玩家成长后回刷旧区域能够更快击杀。
- 本轮只加入生命配置。怪物攻击保持未配置，不设置攻击为零，也不增加反击逻辑。
- 区域与关卡资料已配置，怪物防御、攻速及后续伤害规则仍待确定。

## 当前试玩战斗

- 已开放10个大关，初始普通怪为“尖牙野鼠”，生命60、奖励10修为。完整配置见[levels.md](levels.md)。
- 每次攻击按角色攻击值扣血；怪物不添加攻击、防御或反击数值。
- 普通怪死亡后结算一次修为，再轮换刷新本关下一种普通怪；同关4种普通怪强度相同。怪物配置不读取当前玩家境界。
- 打开游戏后自动攻击，空手每秒一次；初始单次伤害10，沿用原单次攻击计算。手动攻击与自动攻击开关均已取消。
- 切换页面和突破不重复创建计时器，也不重置下一次攻击时间；刷新怪物后继续自动战斗。
- 每关普通怪无限刷新，累计8至44次击杀填满进度后可手动挑战首领；击败首领仅解锁下一关，切换关卡保留进度。首领奖励为5倍同关普通怪修为及10至100固定铜钱。
- 六次跨境界闭关已配置，可突破至大乘期；失败后可以重新积累并再次尝试。
