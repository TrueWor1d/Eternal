# 凡界初版框架

本记录汇总用户已经确认的设定。实现范围以已确认项为准，未知项不以临时机制或默认数值代替。

## 界面

- 采用用户确认的第一种布局：左侧导航，角色信息与战斗区域并排。
- 配色按用户后续意见改为 ChatGPT 深色：深灰主区、较深侧栏、浅色文字与按钮。
- 导航包含战斗、背包、功法、洞府、境界、说明。移除山水装饰和战斗页未开放模块的占位卡片。
- 最近记录默认显示一条，可展开查看最近八条；本次界面调整不改变玩法、数值或解锁规则。
- 战斗展示区左侧使用已选定的简约像素修真者，白灰道袍、束发、空手；战斗与背包装备区使用同一张透明PNG，按像素方式显示。右侧为测试用小灰狼，怪物血条跟随显示在灰狼头顶。灰狼仅是测试外观，不新增正式怪物资料或改动敌怪名称。

## 玩法与修为

- 战斗改为纯自动攻击，修为来自刷怪；突破、导航等仍由玩家操作。
- 进入游戏后自动开始战斗；取消手动攻击与自动攻击开关，点击立绘也不会攻击。
- 当前空手每秒攻击一次，各境界均保持此频率；后期按装备武器影响属性，具体规则待确认。
- 击败怪物获得修为，并可掉落功法。
- 初版现已开放固定的炼气一层普通怪，名字为 `[待编辑]`，生命60、击杀奖励10修为，击败后刷新相同配置。功法掉落仍待资料确认。
- 当前普通怪有20%概率掉落测试物品“铜钱”，成功时随机获得2至5个，自动存入背包并堆叠。
- 直接点击修炼获得修为不作为当前玩法。
- 筑基期解锁洞府后，增加自动修炼这一修为来源。

## 修为体系

世界：凡界，未来增加其他世界。

| 境界 | 小阶段 |
| --- | --- |
| 炼气期 | 一至九层 |
| 筑基期 | 初期、中期、后期、圆满 |
| 金丹期 | 初期、中期、后期、圆满 |
| 元婴期 | 初期、中期、后期、圆满 |
| 化神期 | 初期、中期、后期、圆满 |
| 渡劫期 | 初期、中期、后期、圆满 |
| 大乘期 | 初期、中期、后期、圆满 |

- 小阶段修为达标后可直接突破。
- 大境界突破需要闭关，等待数秒读条后按当前成功率判定。
- 境界越高，基础成功率越低；具体成功率由用户后续提供。
- 成功后进入下一大境界初期。
- 失败扣除部分修为，重新攒够修为后可再次尝试。
- 已确认各阶段所需修为，完整数值见 [balance.md](balance.md)。
- 成功扣除本阶段所需修为，超出部分保留到下一阶段。
- 闭关秒数、成功率及失败扣除量仍待确认。

## 战斗与生命

| 属性 | 玩家 | 怪物 |
| --- | --- | --- |
| 生命值 | 有 | 有 |
| 攻击 | 有 | 暂不配置 |
| 防御 | 有 | 框架保留，数值待定 |
| 攻击速度 | 有 | 框架保留，数值待定 |
| 生命值回复速率 | 有 | 无 |

- 玩家与怪物相互攻击，生命归零时战败。
- 玩家生命回复在战斗、脱战、休整时均生效。
- 玩家战败后休整恢复生命，恢复后可继续挑战。
- 初始生命100、攻击10、防御2、自动攻速1次/秒、生命回复1点/秒，成长曲线已确认并实现，见 [balance.md](balance.md)。
- 普通怪初始生命60、首领300，按怪物自身实力阶段使用相同成长倍率；怪物攻击按用户要求暂不配置。
- 当前玩家单次伤害沿用此前点击攻击的计算，直接使用自身攻击值，初始为10，保持已确认的攻击成长；怪物暂不反击。空手每秒自动攻击一次，切换页面、突破和怪物刷新后持续战斗。
- 包含防御的伤害公式、恢复至何种状态可重新战斗仍待细化。
- 不增加资源或修为损失型战败惩罚。

## 区域推进

- 采用区域刷怪，已解锁区域可反复选择和刷怪。
- 清除一定数量普通怪后解锁该区域首领。
- 随区域难度提升，清怪数量要求提高。
- 击败首领后开放更高一级区域。
- 首领为一次性，击败后不再出现。
- 首领消失后，该区域普通怪仍可重复刷取。
- 普通怪修为奖励参考为10乘以怪物自身实力的成长倍率；具体区域、怪物属性、清怪数量及奖励配置待确认。

## 背包

- 左侧提供“背包”入口，打开后左边为人物装备，右边为角色背包格子；较窄窗口下改为装备在上、背包在下。
- 角色数据包含初始为空的物品列表，作为后续掉落物的存放位置。
- 物品以紧凑格子分页展示，每页24格，桌面约56px、间距8px。24格只限制单页展示，不设置总容量上限。
- 末页恰好填满时自动增加空白下一页；用户也可以在未满时主动进入空白下一页。
- 格子正下方居中放置“上一页、页码、下一页”，第一页禁用上一页；本次游戏内切换页面保留当前页与已打开页数。
- 翻页只改变查看范围，不移动或重排物品；新物品依次显示在后续页，已堆叠的铜钱仍只占原来一格。
- 自动战斗掉落不强制跳转页码、不夺取翻页按钮焦点，查看空白页时显示“本页暂无物品”。
- 初版测试掉落物为“铜钱”：每次击杀独立判定20%概率，成功时等概率抽取2、3、4、5个；未掉落时不增加物品，修为照常结算。
- 铜钱自动进入背包同一个格子，重复获得时累加数量；格子内显示名称及数量，查看背包期间自动战斗的掉落即时更新。
- 其他掉落物、铜钱用途、使用、丢弃、整理或扩容规则后续另行确认。

## 人物装备（暂定）

- 共8个装备槽：头盔1个、护腕2个、靴子2个、胸甲1个、主武器1个、副武器1个。
- 人物装备区以像素主角为中央，两侧从上到下对称排列四排：头盔／胸甲、左护腕／右护腕、主武器／副武器、左靴／右靴。
- 八个装备槽保留名称与未装备状态，中央角色不占用背包物品格子，也不遮挡装备槽。
- 当前仅展示装备空槽，均显示“未装备”；不生成测试装备，不改变角色属性。
- 装备资料、属性、掉落、穿戴和卸下规则后续确认。

## 功法

- 刷怪可掉落功法。
- 装配后获得被动属性加成，部分功法附带主动技能。
- 采用分类槽位。
- 具体类别、类别作用方向、槽位数量、功法内容、掉落规则、技能释放规则尚待确认。
- 未确认的分类建议不作为正式配置。

## 洞府

- 到达筑基期解锁洞府，同时开启自动修炼。
- 升级洞府提高自动修炼的修为收益。
- 具体收益与升级规则待确认。
