# 凡界初版框架

本记录汇总用户已经确认的设定。实现范围以已确认项为准，未知项不以临时机制或默认数值代替。

## 界面

- 采用用户确认的第一种布局：左侧导航，角色信息与战斗区域并排。
- 配色按用户后续意见改为 ChatGPT 深色：深灰主区、较深侧栏、浅色文字与按钮。
- 导航包含战斗、背包、功法、洞府、境界、说明。移除山水装饰和战斗页未开放模块的占位卡片。
- 最近记录默认显示一条，可展开查看最近八条；本次界面调整不改变玩法、数值或解锁规则。
- 战斗展示区左侧为2D修仙小人，右侧为测试用小灰狼，怪物血条跟随显示在灰狼头顶。灰狼仅是测试外观，不新增正式怪物资料或改动敌怪名称。

## 玩法与修为

- 游戏以点击操作为主，修为来自刷怪。
- 玩家可以点击攻击，点击一次攻击一次；也支持自动攻击。
- 击败怪物获得修为，并可掉落功法。
- 初版现已开放固定的炼气一层普通怪，名字为 `[待编辑]`，生命60、击杀奖励10修为，击败后刷新相同配置。功法掉落仍待资料确认。
- 直接点击修炼获得修为不作为当前玩法。
- 筑基期解锁洞府后，增加自动修炼这一修为来源。

## 修为体系

世界：凡界，未来增加其他世界。

| 境界 | 小阶段 |
| --- | --- |
| 炼气期 | 一至九层 |
| 筑基期 | 初期、中期、后期、圆满 |
| 金丹期 | 初期、中期、后期、圆满 |
| 元婴期 | 初期、中期、后期、圆满 |
| 化神期 | 初期、中期、后期、圆满 |
| 渡劫期 | 初期、中期、后期、圆满 |
| 大乘期 | 初期、中期、后期、圆满 |

- 小阶段修为达标后可直接突破。
- 大境界突破需要闭关，等待数秒读条后按当前成功率判定。
- 境界越高，基础成功率越低；具体成功率由用户后续提供。
- 成功后进入下一大境界初期。
- 失败扣除部分修为，重新攒够修为后可再次尝试。
- 已确认各阶段所需修为，完整数值见 [balance.md](balance.md)。
- 成功扣除本阶段所需修为，超出部分保留到下一阶段。
- 闭关秒数、成功率及失败扣除量仍待确认。

## 战斗与生命

| 属性 | 玩家 | 怪物 |
| --- | --- | --- |
| 生命值 | 有 | 有 |
| 攻击 | 有 | 暂不配置 |
| 防御 | 有 | 框架保留，数值待定 |
| 攻击速度 | 有 | 框架保留，数值待定 |
| 生命值回复速率 | 有 | 无 |

- 玩家与怪物相互攻击，生命归零时战败。
- 玩家生命回复在战斗、脱战、休整时均生效。
- 玩家战败后休整恢复生命，恢复后可继续挑战。
- 初始生命100、攻击10、防御2、自动攻速1次/秒、生命回复1点/秒，成长曲线已确认并实现，见 [balance.md](balance.md)。
- 普通怪初始生命60、首领300，按怪物自身实力阶段使用相同成长倍率；怪物攻击按用户要求暂不配置。
- 当前玩家单次伤害使用自身攻击值，怪物暂不反击。手动一次点击触发一击，自动按角色攻速执行，开启自动时仍可点击攻击。
- 包含防御的伤害公式、恢复至何种状态可重新战斗仍待细化。
- 不增加资源或修为损失型战败惩罚。

## 区域推进

- 采用区域刷怪，已解锁区域可反复选择和刷怪。
- 清除一定数量普通怪后解锁该区域首领。
- 随区域难度提升，清怪数量要求提高。
- 击败首领后开放更高一级区域。
- 首领为一次性，击败后不再出现。
- 首领消失后，该区域普通怪仍可重复刷取。
- 普通怪修为奖励参考为10乘以怪物自身实力的成长倍率；具体区域、怪物属性、清怪数量及奖励配置待确认。

## 背包

- 左侧提供“背包”入口，打开角色背包，以小格子显示物品。
- 角色数据包含初始为空的物品列表，作为后续掉落物的存放位置。
- 当前空格只用于展示，不设置容量上限；物品增加时可继续显示更多格子。
- 未添加掉落物、堆叠、使用、丢弃、整理或扩容规则，这些内容后续另行确认。
- 未配置掉落时，当前刷怪只获得已确认的修为，不产生背包物品。

## 功法

- 刷怪可掉落功法。
- 装配后获得被动属性加成，部分功法附带主动技能。
- 采用分类槽位。
- 具体类别、类别作用方向、槽位数量、功法内容、掉落规则、技能释放规则尚待确认。
- 未确认的分类建议不作为正式配置。

## 洞府

- 到达筑基期解锁洞府，同时开启自动修炼。
- 升级洞府提高自动修炼的修为收益。
- 具体收益与升级规则待确认。
