# 凡界初版框架

本记录汇总用户已经确认的设定。实现范围以已确认项为准，未知项不以临时机制或默认数值代替。

## 界面

- 文字对齐标准：文字默认在各自所属容器中水平、垂直居中；宽栏中的页面标题等文字不强制水平居中，例如“战斗”标题保留左对齐，保持上下留白一致。当前仅登记规则，暂不修改界面。

- v0.1.13全局标准：所有栏目横向分隔线必须连接所在容器左右边缘，文字和控件保留内边距。相邻栏目用连续1px细线分隔，桌面背包竖线连接上下边界；境界与关卡弹窗列表采用行分隔。窄屏各栏目分隔线同样连接对应容器边缘。后续新增栏目遵守此标准。

- v0.1.12将游戏命名为“永恒”，左栏顶部标题水平居中；沿用原有字体、字号、字重与配色，浏览器标题同步改名。

- 按v0.1.9要求，角色信息移到最左侧栏顶部，主导航排在下方，并缩短区块、属性行与菜单的纵向间距。角色信息在各页面持续可见，主内容区不再保留中间的角色信息列。窄屏时角色信息与属性在顶部并排显示，导航紧随其下。
- 配色按用户后续意见改为 ChatGPT 深色：深灰主区、较深侧栏、浅色文字与按钮。
- 导航仅包含战斗、背包、功法、洞府。v0.1.16移除独立境界与说明资料页、待确认内容弹窗；资料保留在 [realms.md](realms.md)、[balance.md](balance.md)与[game-rules.md](game-rules.md)，供开发读取。角色信息中的当前境界和突破操作保留。移除山水装饰和战斗页未开放模块的占位卡片。
- 最近记录默认显示一条，可展开查看最近八条；
- 战斗展示区左侧使用已选定的简约像素修真者，白灰道袍、束发、空手；战斗区按像素方式显示；v0.1.14装备区移除人物立绘。右侧为测试用小灰狼，怪物血条跟随显示在灰狼头顶。灰狼仅是测试外观，不新增正式怪物资料或改动敌怪名称。

- 战斗区已移除击杀奖励、自动攻击说明和清怪提示三行文字。v0.1.11改用一条首领进度与“挑战首领”按钮，关卡列表收进“选择关卡”弹窗。
- 修为实际到账时在左栏当前修为数字上方显示“+数值”，450毫秒内上浮并消失；导航清理旧提示，连续到账不堆积。减少动态效果时改为静态提示，不执行位移动画。

## 玩法与修为

- 战斗改为纯自动攻击，修为来自刷怪；突破、导航等仍由玩家操作。
- 进入游戏后自动开始战斗；取消手动攻击与自动攻击开关，点击立绘也不会攻击。
- 当前空手每秒攻击一次，各境界均保持此频率；后期按装备武器影响属性，具体规则待确认。
- 击败怪物获得修为，并可掉落功法。
- 初始关卡“山野小径”的4种普通怪均为炼气一层实力，生命60、击杀奖励10修为；击败后轮换刷新。功法掉落仍待资料确认。
- 当前普通怪有20%概率掉落测试物品“铜钱”，成功时随机获得2至5个，自动存入背包并堆叠。
- 直接点击修炼获得修为不作为当前玩法。
- 筑基期解锁洞府后，增加自动修炼这一修为来源。

## 修为体系

世界：凡界，未来增加其他世界。

| 境界 | 小阶段 |
| --- | --- |
| 炼气期 | 一至九层 |
| 筑基期 | 初期、中期、后期、圆满 |
| 金丹期 | 初期、中期、后期、圆满 |
| 元婴期 | 初期、中期、后期、圆满 |
| 化神期 | 初期、中期、后期、圆满 |
| 渡劫期 | 初期、中期、后期、圆满 |
| 大乘期 | 初期、中期、后期、圆满 |

- 小阶段修为达标后可直接突破。
- 大境界突破需要闭关，等待数秒读条后按当前成功率判定。
- 境界越高，基础成功率越低；v0.1.8为完整关卡推进配置了六次闭关参数。
- 成功后进入下一大境界初期。
- 失败扣除部分修为，重新攒够修为后可再次尝试。
- 已确认各阶段所需修为，完整数值见 [balance.md](balance.md)。
- 成功扣除本阶段所需修为，超出部分保留到下一阶段。
- 六次跨境界闭关依次耗时5至10秒，成功率依次为80%、70%、60%、50%、40%、30%，失败扣除当前突破门槛的10%。闭关期间自动战斗继续。

## 战斗与生命

| 属性 | 玩家 | 怪物 |
| --- | --- | --- |
| 生命值 | 有 | 有 |
| 攻击 | 有 | 暂不配置 |
| 防御 | 有 | 框架保留，数值待定 |
| 攻击速度 | 有 | 框架保留，数值待定 |
| 生命值回复速率 | 有 | 无 |

- 玩家与怪物相互攻击，生命归零时战败。
- 玩家生命回复在战斗、脱战、休整时均生效。
- 玩家战败后休整恢复生命，恢复后可继续挑战。
- 初始生命100、攻击10、防御2、自动攻速1次/秒、生命回复1点/秒，成长曲线已确认并实现，见 [balance.md](balance.md)。
- 普通怪初始生命60、首领300，按怪物自身实力阶段使用相同成长倍率；怪物攻击按用户要求暂不配置。
- 当前玩家单次伤害沿用此前点击攻击的计算，直接使用自身攻击值，初始为10，保持已确认的攻击成长；怪物暂不反击。空手每秒自动攻击一次，切换页面、突破和怪物刷新后持续战斗。
- 包含防御的伤害公式、恢复至何种状态可重新战斗仍待细化。
- 不增加资源或修为损失型战败惩罚。

## 区域推进

- 共10个大关卡，每关4种普通怪和1名一次性首领；名称见 [levels.md](levels.md)，不设置小关卡。
- 进入已解锁关卡后，4种普通怪按顺序无限轮换刷新，共享本关固定强度；普通怪击杀累计填充本关首领进度。
- 首领进度目标从第1关8只逐关增加4只，至第10关44只。满进度后继续刷怪，进度显示封顶，手动点击“挑战首领”才进入首领战。
- 击败首领后仅开放下一关，留在当前关继续刷普通怪；首领奖励只结算一次，不可重复挑战。
- 战斗区只保留一个“选择关卡”入口，点击弹出10个关卡；未解锁项右侧显示锁图标，按钮禁用，已解锁项可切换进入。
- 切换关卡保留各关击杀数与首领状态；重复选择正在刷怪的当前关，不重置当前怪物生命。选择当前关或其他已解锁关可离开首领战、继续刷普通怪。
- 10关实力沿33阶段成长曲线插值，普通怪生命为60乘倍率、修为为10乘倍率；首领为同关普通怪的5倍生命与修为，固定奖励关卡序号乘10的铜钱。
- 所有关卡通关后仍可无限刷普通怪。当前没有存档，刷新页面重置进度。

## 背包

- 左侧提供“背包”入口，打开后左边为人物装备，右边为角色背包格子；较窄窗口下改为装备在上、背包在下。
- 初始物品列表包含10件测试装备，每个装备槽对应一件，两个戒指有独立ID。
- 物品以紧凑格子分页展示，每页24格，桌面约56px、间距8px。24格只限制单页展示，不设置总容量上限。
- 末页恰好填满时自动增加空白下一页；用户也可以在未满时主动进入空白下一页。
- 格子正下方居中放置“上一页、页码、下一页”，第一页禁用上一页；本次游戏内切换页面保留当前页与已打开页数。
- 翻页只改变查看范围，不移动或重排物品；新物品填充第一个空格，已堆叠的铜钱仍只占原来一格；手动拖动后按独立位置显示，不自动挤紧。
- 自动战斗掉落不强制跳转页码、不夺取翻页按钮焦点，查看空白页时显示“本页暂无物品”。
- 初版测试掉落物为“铜钱”：每次击杀独立判定20%概率，成功时等概率抽取2、3、4、5个；未掉落时不增加物品，修为照常结算。
- 铜钱自动进入背包同一个格子，重复获得时累加数量；格子内显示名称及数量，查看背包期间自动战斗的掉落即时更新。
- 其他掉落物、铜钱用途、使用、丢弃、自动整理或扩容规则后续另行确认。

## 人物装备（暂定）

- 共10个装备槽：头盔、项链、主武器、胸甲、副武器、护腕、裤子、鞋子各1个，戒指2个。
- 装备区不展示人物立绘，使用四行三列：首行“空／头盔／项链”，第二行“主武器／胸甲／副武器”，第三行“护腕／裤子／戒指”，第四行“空／鞋子／戒指”。空位不绘制槽位。
- 槽位尺寸一致，名称和未装备状态在各自格内居中；窄屏保留相同排列。
- v0.1.17初始生成10件“测试用＋部位名”装备，均在背包中。支持鼠标和触屏按部位拖动穿戴、卸回背包、替换和戒指互换；背包物品可拖动换格。
- 背包选中格显示2px边框，选中状态与位置在本次游戏内保留；键盘和点击提供同等穿脱操作。无效放置或取消拖动不改变物品。
- 拖动期间自动战斗与掉落照常结算，结束拖动后刷新背包，避免DOM重建打断操作。
- v0.1.18右键背包物品，在物品右侧弹出三行菜单，顺序为装备、分解、出售；边缘空间不足时换侧或限制在视口内。装备优先兼容空槽，无空槽时替换第一个兼容槽，旧装备返回来源背包格。
- 分解与出售按用户确认直接移除指定背包装备，暂不给材料或铜钱，不影响其他装备或已穿戴物品；非装备物品这三项操作暂不开放。
- 菜单支持键盘打开、方向键与回车操作，Escape、外部点击、翻页、切换页面和拖动关闭；自动掉落保留菜单与焦点。
- v0.1.19采用六档颜色边框：常见白、普通绿、稀有蓝、罕见紫、珍稀金、绝世红。游戏内不显示稀有度名称；配置见src/game/rarity.ts。
- 背包及装备槽为直角框，有物品时3px厚边及轻微内沿高光，空槽1px灰框；物品名称原色。选中为白色四角与背景提亮，白线距边框约1px。
- 测试装备按槽位顺序循环六档，铜钱为常见。穿戴、卸下、交换与堆叠均保留稀有度；不改变属性或收益。正式装备资料、属性与掉落后续确认。

## 功法

- 刷怪可掉落功法。
- 装配后获得被动属性加成，部分功法附带主动技能。
- 采用分类槽位。
- 具体类别、类别作用方向、槽位数量、功法内容、掉落规则、技能释放规则尚待确认。
- 未确认的分类建议不作为正式配置。

## 洞府

- 到达筑基期解锁洞府，同时开启自动修炼。
- 升级洞府提高自动修炼的修为收益。
- 具体收益与升级规则待确认。
